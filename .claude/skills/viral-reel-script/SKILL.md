# Viral Reel Script

## What this skill produces

Given a topic (and optionally: niche, audience, goal, tone, length, language), produce
ONE complete, ready-to-film package. Always deliver all of these parts, in this order:

1. **3 hook variations** (so the user can A/B test) — each ≤ 12 words / ~1–2 sec spoken.
2. **The chosen format** + why it fits (pick from the format library below).
3. **Full spoken script** broken into timed beats (Hook → Body → Payoff → CTA), with
   a running timestamp and a target total length.
4. **On-screen text plan** — the exact words to overlay, beat by beat (≈85% watch muted).
5. **Caption** — opens by re-stating the hook, delivers the core value, ends with the CTA.
6. **Hashtags** — 3–7, mixing broad + niche + content-specific.
7. **B-roll / shot notes** — one short line per beat so it's actually filmable.
8. **One "why this works"** line naming the psychological lever used.

Do not stop after the script alone. The deliverable is the *whole package*.

## How to run this skill (workflow)

1. **Read the topic.** If the user gave niche/audience/goal/tone/length, use them. If a
   critical piece is missing, make ONE sensible assumption and state it inline rather
   than stalling — do not interrogate the user with many questions.
2. **Decide if a quick web search is warranted.** Search when the topic depends on
   current facts, fresh trends, prices, new products, or anything post-cutoff. For
   timeless/evergreen topics, skip the search and write directly. (The user explicitly
   wants searches done *before* writing when fuller info would help.)
3. **Pick ONE format** from `references/formats.md` that matches the goal.
4. **Write the package** using `references/techniques.md` for hooks, retention, pacing,
   CTA, and the algorithm rules. Keep every rule in `references/rules.md`.
5. **Match the output language to the topic.** Persian topic → Persian output, RTL,
   natural spoken register (not bookish). Keep numbers/units sensible for the locale.
6. **Output format:** for a single script, respond inline in chat (it's a script the
   user will copy). Only create a file (.docx/.md) if the user asks for a document,
   a batch of many scripts, or a downloadable deliverable.

## The non-negotiable spine of every script

- **First 1–2 seconds = the hook = the promise.** No "سلام دوستان", no warm-up, no
  channel intro. The payoff or boldest line goes in the very first frame.
- **One reel, one idea, one goal.** The goal is exactly one of: be shared, be saved,
  start a conversation, or earn a follow. If the idea can't be said in one sentence,
  it isn't ready.
- **Open a loop, close it at the end.** Raise a question/tension early; resolve it only
  at the payoff. Mid-loops (mini cliffhangers) hold the middle.
- **On-screen text mirrors the spoken hook**, because most viewers watch muted and
  because matching audio + text + caption helps the algorithm classify the topic.
- **Target length 15–30 sec** for max virality; go to 30–60 only with a stronger hook
  and tighter pacing. Shorter almost always wins on completion rate.
- **Honest hooks only.** The hook must accurately preview the content. Bait-and-switch
  gets the 3-second hold but destroys long-term reach and trust.

For the full toolbox (hook formulas, psychological triggers, format templates, CTA
menu, retention tactics, the 2026 algorithm signals, and the hard rules), read the
three reference files before writing:

- `references/techniques.md` — hooks, psychology, pacing, CTA, algorithm.
- `references/formats.md` — plug-and-play script structures by goal.
- `references/rules.md` — the do/don't checklist and self-check before delivering.
