# Rules & self-check (read before delivering any script)

## Always
- Lead the hook with the promise/payoff in the first 1–2 seconds; no warm-up.
- Keep the hook ≤ 12 words and mirror it as the first on-screen text.
- One reel = one idea = one goal (share / save / comment / follow).
- Open a curiosity loop early; close it only at the payoff.
- Deliver the FULL package: 3 hooks, format+why, timed script, on-screen text,
  caption, hashtags, shot notes, "why it works" line.
- Match output language to the topic; for Persian use natural spoken RTL register.
- Keep the script honest — the hook must accurately preview the content.
- Default to 15–30 sec; justify anything longer with a stronger hook.
- Pick exactly one CTA, on-platform (save/share/comment/DM), specific not generic.

## Never
- Never open with "سلام دوستان / hey guys / welcome / so today…".
- Never write a hook you can't pay off (bait-and-switch tanks reach and trust).
- Never use a generic CTA like a bare "follow for more" when a specific ask fits.
- Never recommend cross-posting with a TikTok/competitor watermark.
- Never over-promise medical/financial/legal outcomes; use responsible framing
  ("can help with", "in traditional medicine", "in my experience"), and add a brief
  caution where a claim could mislead or cause harm.
- Never bury the payoff at the end of a long intro; move it to the first frame.
- Never pad to hit a length — tighter is better for completion rate.

## Sensitive / claim-heavy niches (health, money, law, religion)
- Use cautious, accurate language; avoid guarantees of cure/profit/outcome.
- Separate "what tradition/sources say" from "what evidence shows" when both exist.
- For religious content, attribute sources accurately and avoid fabricated quotes.
- Keep it respectful; sparking thought is fine, mocking belief is not.

## Final self-check (answer before sending)
1. Does the first line state the promise with zero warm-up?
2. Is there an open loop that the payoff actually closes?
3. Is the on-screen text readable and mirroring the hook?
4. Is there exactly ONE clear goal and ONE matching CTA?
5. Is the total length ≤ 30s (or justified if longer)?
6. Is the hook honest about what the body delivers?
7. Did I include every part of the package?
8. Is the language/register right for the audience?
